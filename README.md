# Planned Inventory Analysis – Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **Power BI dashboard for Planned Inventory Analysis**, designed to support inventory planning and supply chain decision-making.

The dashboard provides a consolidated view of inventory value, stock levels, consumption, delivery, inventory turnover, product/category distribution, stock balance, and planned inventory performance.

The main objective is to transform inventory data into actionable insights that can help planners identify excess stock, unbalanced inventory, consumption trends, and potential inventory risks.

> **Note:** The data and sensitive business information presented in this portfolio version have been anonymized and/or blurred for confidentiality purposes. The dashboard structure and analytical approach are representative of a real-world inventory planning use case.

---

## 🎯 Project Objectives

The dashboard was developed to answer key inventory planning questions such as:

- What is the current inventory value?
- How is inventory expected to change over time?
- How does planned consumption compare with actual consumption?
- How does delivery affect future inventory levels?
- Which categories and components hold the highest inventory value?
- Which models have the highest available stock?
- Where is inventory unbalanced?
- What is the current stock distribution by status?
- How is inventory distributed across regions?
- Which brands/products contribute most to the inventory value?
- How does planned stock compare with the current inventory situation?
- Is the inventory turnover within the desired target?

## 📌 Dashboard Sections

### 1. Inventory KPIs

The top section provides a quick overview of the main inventory indicators:

- Initial Stock Value
- Balance Inventory %
- Inventory Turnover
- Inventory Value of Sales
- Inventory Turnover Target

These KPIs provide a high-level snapshot of the inventory situation.

---

### 2. Planned Inventory Values

This trend analysis compares:

- Stock
- Consumption
- Delivery

across multiple months.

The purpose is to understand how planned consumption and incoming deliveries are expected to influence future inventory levels.

This view can help planners identify periods where:

- Consumption exceeds delivery
- Stock is expected to decline
- Inventory may accumulate
- Additional planning actions may be required

---

### 3. Planned vs. Actual Inventory

The dashboard compares planned and actual inventory values over time.

This analysis helps identify:

- Planning deviations
- Actual vs. planned performance
- Periods of overestimation or underestimation
- Trends in inventory development

---

### 4. Current Situation Analysis – Categories

The category analysis provides a comparison between:

- Actual Stock
- Planning Consumption
- Actual Consumption

This helps identify the categories that represent the largest share of inventory and highlights areas where consumption behavior may differ from the existing stock position.

---

### 5. Current Situation Analysis – Components

The component-level analysis provides a more detailed view of inventory distribution.

It allows planners to identify:

- High-value components
- Components with relatively high stock
- Consumption patterns
- Potential excess inventory
- Components requiring further investigation

---

### 6. Available KG by Model

This section ranks models according to their available inventory quantity.

It can be used to identify models with:

- High available quantities
- Low stock
- Potential excess inventory
- Significant inventory exposure

---

### 7. Unbalanced Stock Analysis

The dashboard highlights inventory that may be considered unbalanced.

The analysis combines stock quantities and inventory-related indicators with planning consumption to help identify items that may require further investigation.

Potential actions could include:

- Adjusting future purchase requirements
- Reviewing production plans
- Increasing consumption
- Reallocating stock
- Reviewing safety stock parameters

---

### 8. Best Mix by Brand and Product

This analysis visualizes the contribution of different products/brands to the overall inventory mix.

It helps identify:

- Major inventory contributors
- Product mix concentration
- High-value product groups
- Opportunities for inventory optimization

---

### 9. Balanced Stock Gauge

The gauge provides a visual indication of the current inventory balance compared with the defined target.

It can be used as a quick management-level indicator for inventory health.

---

### 10. Stock by Status

The dashboard analyzes inventory according to stock status, including categories such as:

- Active
- Slow Moving
- Non Moving

This provides visibility into inventory quality and helps identify potentially problematic stock.

---

### 11. Stock by Region

Inventory is also analyzed geographically to identify how stock is distributed across different regions.

This can support:

- Inventory allocation decisions
- Regional stock balancing
- Identification of inventory concentration
- Distribution planning

---

### 12. Stock Analysis by Brand

The final section provides a monthly stacked analysis of inventory by brand/product group.

This allows users to track:

- Monthly inventory development
- Brand contribution
- Changes in inventory composition
- Overall stock trends

---

## 📈 Key KPIs

The dashboard focuses on several important Supply Chain and Inventory KPIs:

| KPI | Purpose |
|---|---|
| Inventory Value | Measures the financial value of inventory |
| Inventory Turnover | Measures how efficiently inventory is being consumed/sold |
| Balance Inventory % | Indicates the proportion of balanced inventory |
| Actual Stock | Shows the current inventory position |
| Planned Stock | Shows the expected inventory position |
| Actual Consumption | Measures actual inventory consumption |
| Planning Consumption | Represents expected consumption |
| Delivery | Represents expected incoming supply |
| Slow Moving Stock | Identifies inventory with low movement |
| Non-Moving Stock | Identifies inventory with no/very limited movement |
